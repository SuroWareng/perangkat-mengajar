# Program Tahunan (Prota)

Program Tahunan adalah rencana pembelajaran selama satu tahun ajaran yang mencakup semua materi pokok dan alokasi waktu.

## Isi Prota

1. **Identitas Sekolah** - Nama, alamat, tahun ajaran
2. **Mata Pelajaran** - Nama mata pelajaran
3. **Kelas/Semester** - Target kelas dan semester
4. **Kompetensi Inti dan Dasar**
5. **Materi Pokok** - Daftar materi sepanjang tahun
6. **Alokasi Waktu** - Jumlah jam per materi
7. **Keterangan**

## Template

Lihat folder `templates/` untuk file template Prota dalam format:
- Excel (.xlsx)
- Word (.docx)
- Markdown (.md)

## Contoh Penggunaan

1. Buka template sesuai format yang diinginkan
2. Isi data identitas sekolah
3. Masukkan materi pokok dan alokasi waktu
4. Simpan dalam folder `data/`

## File yang Tersedia

- `templates/prota_template.xlsx` - Template Excel
- `templates/prota_template.docx` - Template Word
- `templates/prota_template.md` - Template Markdown
