# Modul Ajar

Modul Ajar adalah materi pembelajaran yang dirancang untuk satu kompetensi dasar atau satu bagian dari kompetensi dasar, dengan alokasi waktu tertentu.

## Isi Modul Ajar

1. **Informasi Umum** - Judul, KD, durasi, dll
2. **Tujuan Pembelajaran**
3. **Pemahaman Bermakna**
4. **Pertanyaan Pemantik**
5. **Kegiatan Pembelajaran**
6. **Asesmen/Penilaian**
7. **Refleksi Peserta Didik**
8. **Lampiran** - Lembar kerja, rubrik, dll

## Template

Lihat folder `templates/` untuk file template Modul Ajar dalam format:
- Word (.docx)
- Markdown (.md)
- PDF (.pdf)

## Contoh Penggunaan

1. Buka template sesuai format yang diinginkan
2. Isi informasi umum modul
3. Tentukan tujuan pembelajaran
4. Rancang kegiatan pembelajaran
5. Siapkan instrumen penilaian
6. Tambahkan lampiran pendukung
7. Simpan dalam folder `contoh/`

## File yang Tersedia

- `templates/modul_ajar_template.docx` - Template Word
- `templates/modul_ajar_template.md` - Template Markdown
- `contoh/modul_ajar_contoh.md` - Contoh modul yang sudah jadi
