# Perangkat Mengajar - Kurikulum Nasional 2026

## 🎓 Update Besar: Struktur Kurikulum 2026

Aplikasi telah diupdate untuk mendukung **Kurikulum Nasional 2026** dengan fitur-fitur baru:

✅ **Profil Pelajar Pancasila (P5)** - Integrasi karakter dalam pembelajaran
✅ **Capaian Pembelajaran (CP)** - Menggantikan KD sistem lama  
✅ **Elemen Pembelajaran** - Pengelompokan kompetensi yang lebih fleksibel
✅ **Mata Pelajaran Baru** - Koding & Kecerdasan Artifisial

✅ **Kurikulum Satuan Pendidikan** - Fleksibilitas sesuai konteks lokal

## 🚀 Instalasi & Menjalankan

### Quick Start (5 Menit)

```bash
# 1. Clone atau download repository
git clone https://github.com/SuroWareng/perangkat-mengajar.git
cd perangkat-mengajar

# 2. Install dependencies
pip install -r requirements.txt

# 3. Jalankan aplikasi
python run.py

# 4. Buka browser
http://localhost:5000
```

**Dokumentasi lengkap:** Baca `INSTALL.md`


## ⚡ Tips Implementasi 2026

### ✅ Do's:
- ✓ Pahami Capaian Pembelajaran dengan baik
- ✓ Integrasikan P5 dalam setiap pembelajaran
- ✓ Gunakan 20% waktu untuk proyek nyata
- ✓ Berkolaborasi dengan guru mata pelajaran lain
- ✓ Dokumentasikan pembelajaran siswa
- ✓ Lakukan refleksi berkelanjutan

### ❌ Don'ts:
- ✗ Terlalu rigid dengan alokasi waktu
- ✗ Lupakan pengintegrasian P5
- ✗ Gunakan proyek hanya di akhir semester
- ✗ Abaikan konteks lokal & inovasi sekolah
- ✗ Fokus hanya nilai, lupakan karakter
