# Program Semester (Promes)

Program Semester adalah rencana pembelajaran dalam satu semester yang lebih detail dibanding Prota, mencakup minggu demi minggu.

## Isi Promes

1. **Identitas Sekolah** - Nama, alamat, tahun ajaran
2. **Semester** - Semester 1 atau 2
3. **Kompetensi Dasar**
4. **Materi Pembelajaran**
5. **Alokasi Waktu Per Minggu**
6. **Bulan Pembelajaran**
7. **Hari Libur dan Cadangan**

## Template

Lihat folder `templates/` untuk file template Promes dalam format:
- Excel (.xlsx)
- Word (.docx)
- Markdown (.md)

## Contoh Penggunaan

1. Buka template sesuai format yang diinginkan
2. Isi data identitas sekolah dan semester
3. Masukkan materi per minggu
4. Hitung alokasi waktu
5. Tambahkan jadwal libur dan cadangan
6. Simpan dalam folder `data/`

## File yang Tersedia

- `templates/promes_template.xlsx` - Template Excel
- `templates/promes_template.docx` - Template Word
- `templates/promes_template.md` - Template Markdown
